# 🛡️ ScamShield – UPI Safety Checker

**Think Before You Pay. Stay Alert. Stay Safe.**

## 📌 About the Project

ScamShield is a web-based UPI fraud awareness and safety checker designed to help users recognize potential online payment scams. It analyzes suspicious messages, UPI QR codes, and website links to highlight warning signs and provide practical safety recommendations.

The project aims to promote safer digital payments and help users make more informed decisions before sharing sensitive information or making transactions.

## ✨ Key Features

- 💬 **Suspicious Message Checker:** Analyzes messages for common scam indicators, including fake KYC alerts, OTP requests, refund scams, prize scams, and digital arrest threats.
- 📷 **UPI QR Code Checker:** Reads QR codes or UPI payment links and displays payment details, such as the recipient and amount, when available.
- 🔗 **Website Link Checker:** Examines website links for potential warning signs, using link previews and domain information.
- 🤖 **AI-Powered Analysis:** Offers an optional second opinion using Google Gemini when configured with an API key.
- 🎙️ **Voice Input:** Supports speech input in English, Hindi, and Gujarati where the browser provides speech recognition.
- 🚨 **Fraud Response Guidance:** Provides steps to take after a suspected scam, including contacting India's cyber fraud helpline at 1930.
- 🧪 **Demo Examples:** Includes sample messages and scam scenarios for learning and testing.
- 🌙 **Responsive Interface:** Provides a user-friendly interface with light and dark theme support.

## 🛠️ Technologies Used

- **HTML5** – Structures the website.
- **CSS3** – Provides styling, responsive layouts, and theme support.
- **JavaScript** – Implements scam-detection rules, QR analysis, link checks, and user interactions.
- **jsQR** – Reads QR codes from uploaded images.
- **Google Gemini API** – Provides optional AI-assisted analysis.
- **Microlink** – Supports remote website screenshots and link inspection.
- **RDAP** – Retrieves domain registration information where available.
- **GitHub Pages** – Can be used to host the website publicly.

## 🚀 How to Run the Project

### Option 1: Run Locally

1. Download or clone this repository.
2. Locate the `index.html` file.
3. Open `index.html` in a modern web browser.
4. Test the message checker, QR checker, and link checker.

**Note:** An internet connection is needed for external libraries and online services. Some features depend on third-party service availability and configuration.

### Option 2: Run Online

1. Open the published GitHub Pages website.
2. Select the feature you want to try.
3. Enter a sample suspicious message, upload a QR image, or enter a website link.
4. Review the warning signs and recommended safety actions.

### Optional AI Setup

To use AI-assisted analysis, open the website's AI settings and configure a valid Google Gemini API key. Follow the instructions displayed in the website.

**Security note:** Do not share your API key publicly or commit it to GitHub. For a public deployment, avoid exposing private API keys in client-side JavaScript.

## 🎯 Project Objective

The objective of ScamShield is to increase awareness of digital payment fraud, educate users about common scam techniques, and encourage safe online payment habits.

## ⚠️ Disclaimer

ScamShield is an educational hackathon prototype. Its rule-based checks and optional AI analysis can make mistakes, miss scams, or flag legitimate content. A low-risk result does not guarantee that a message or website is safe. Always verify payment requests independently and never share your UPI PIN or OTP.
